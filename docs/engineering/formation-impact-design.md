# 布阵与击破体验设计

用户选择“需要布阵，但打起来很爽”，并已批准第一轮：黄巾波内节奏＋五关共用攻击和击破表现。

## 玩家体验

位置、技能几何及升级带来真实收益，战斗以短批密集兵、精英压力、整备间隙形成起伏。吕布扇形、赵云穿透、诸葛亮减速与周瑜火区沿用现有规则；不把关羽的持续单点画成范围伤害。

## 首批范围

1. 黄巾仅重新安排普通兵组的波内出兵时刻，以小批成组、批间留空形成局部密度。保持每波敌军种类、数量、路线、生命／速度倍率、赏金、波间等待、Boss出现延迟；其余四关配置逐字段保持。前三波教学继续适用。
2. 五关共用表现突出吕布扇形与赵云贯穿轨迹，同次范围攻击合并主轨迹，命中仍根据真实敌军事件显示。太史慈双矢、袁绍多目标箭雨等独立目标弹道保留，不能统一按武将短窗吞掉。控制、持续火区及原预警保留。没有命中的地方不产生伤害数字。
3. 连续短时真实击退达到阈值时显示一条“连破 ×N”，不宣称是同一招、不归功于指定武将，不加奖励、倒计时惩罚或连击任务。依据唯一有效敌军实例编号计数，普通密集反馈合并，预警始终清楚。小屏连破文字使用足够行高与深色细描边，回池后普通数字不继承该样式。
4. 击退保留短促的局部光点／退场；不加入全屏闪光、震屏、强制慢放或阻塞结算。原90个特效／14个数字及音频声部限制保持。

## 验收

- 对比旧配置快照，黄巾每波敌军总数／定义／倍率／赏金与原来一致；非黄巾四关完全一致。检验生成器数据与实际database.json一致，历史美术不变。
- 主推及替代两套核心不同的合法阵容均可胜利，逐笔消费、收入、奖励和补给对账；记录新时长、城防、漏兵、首次升级及出兵峰值，不把旧408秒当新结果。
- Unity真实图形检查攻击方向、范围、合并、实际击退计数、暂停冻结、清空／复用、密集池上限与重要预警；真实按钮流程及新手／复盘回归保留。
- 1920×1080、1280×720、2400×1080实图，抽查密集战斗可读性；两平台重建、源码副本指纹及APK验签。
- 自动模拟及离屏渲染不等于玩家乐趣、手机触控、实际听感或真机性能验收。
