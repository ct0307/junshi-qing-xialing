# 黄巾精品样板与体验推广实施计划

目标：将现有核心原型推进为完整可审阅的黄巾样板关，共用体验改善覆盖五关。用户已批准此方向，无需重复询问实施方式。

架构：纯C# BattleSession继续拥有战斗时钟与规则；公开只读战况和消费统计。Presentation读取这些信息，新增独立情报/布阵提示与黄巾场景；动画沿统一游戏时钟推进，所有装饰避让交互层。现有uGUI、Unity 6000.3.28f1，不新增依赖。

- [x] 在DomainTests先添加倒计时、待出兵、暂停与终局归零、消费及失败原因断言，观察缺失接口导致失败。
- [x] Domain新增IsWaveActive、NextWaveCountdown、RemainingEnemies、DefeatedCount、LeakedCount、GoldSpent、DefeatReason，只读查询不消费事件。
- [x] 黄巾推荐与替代阵容通过真实招募/升级和正常军饷推进，输出首次升级、时长、城防和Boss结果；根据证据决定是否调整配置。

- [x] BattleView顶栏Boss未登场时显示真实下一波名称、敌型、倒计时；活跃波显示剩余兵力；Boss入场后保留血量及危险预告。
- [x] 根据未部署/已选将/已部署/缺钱/战斗中状态给出短指引；选中位置使用独立标记，布阵时显示真实射程覆盖道路。
