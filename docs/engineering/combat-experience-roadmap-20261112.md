## 最新决策：布阵竞速为核心（2026-11-19）

用户明确核心乐趣为不断挑战更高进军倍率、刷新个人最快，并授权综合选择最优方案。已选定并落地“普通通关保留容错＋全Boss击退主竞速＋动态倍率同榜”，自动验收通过，真人／真机待验。完整规则与设计依据见[布阵竞速核心玩法改进方案](race-defense-improvement-20261119.md)，实际结果见本页顶部。

- 1×／2×／3×可动态切换，同关同版本按有效运行实秒比较，不按倍率另拆榜、不因触碰3×额外加分；更高倍率暂后置。
- 普通通关沿用全部波次完成且城防仍存即可胜利、Boss突破扣15；新“竞速最快”要求配置中的Boss全部实际生成并真实击退、Boss突破为0，允许普通漏兵。
- 新主竞速与旧普通最快分开，保留旧最快、最近、通关及城防数据，不根据旧快照补认证或清档。新增Boss实例对账与跨帧率计时验收，不能用Boss禁选名单数量或界面事件文本证明击退完成。
- P1为竞速资格与记录契约、倍率说明、纪录差值反馈、招募／军势／升阶取舍及关卡提速窗口；P2为低成本再试、可靠复盘和倍率策略摘要；P3为少将等附加挑战。此前“竞速仅作附加重玩”的建议由此替代。
- 已认可的UI九项方向保留；首批顶栏、军令台、升级区围绕提速与破纪录决策精修。倍率说明由P2提升为P1，沿用原条目，不重复新建。
- 顺序为先冻结Boss、计时、成绩契约，再落地说明与结算UI，再逐关验证更快策略，最后扩复盘和附加挑战。普通兵统一降血、批次加密和全体增伤先作为有证据后的小范围实验。

该决策记录时仅为方案；现已按顶部交付落地。下文历史候选与旧阶段顺序在冲突时以竞速专项为准；不能把真人／真机目标当作已通过证据。

## 已认可新增改进：进军倍率说明（2026-11-19）

优先级：P1（随竞速核心定位由原P2提升）。状态：用户已认可，待实施。本次仅补充方案，游戏代码、倍率规则、数值与现有安装包均未修改。

目标：让玩家首次使用加速进军时，理解来敌压力会提高，避免按普通全局快进预期操作。当前规则页和切换短通知已有基础解释；本项强化首次说明和理解验收。

- 按钮保留“进军 1×／2×／3×”，统一称为“进军倍率”。
- 首次从1×切换至2×时展示一次可读说明；后续切换保留简短提醒，完整规则随时可查，不因重试反复打断玩家。
- 正常确认说明后保存独立已读标记，重试或重启不重复自动弹出；未确认即退出或中断时不视为已读，既有成绩不受影响。
- 首次说明采用暂停阅读，阅读期间不推进战斗或实际用时、不产生计时军饷；关闭后仅恢复此前正在运行的战斗，备战或暂停状态保持。
- 完整说明明确：敌军移动、出兵与计时军饷加快，波间等待缩短；我方普攻、技能冷却与实际用时不随倍率加速。

首次说明建议文案：“加速进军会加快来敌和军饷增长，我方攻击与技能速度不变，守关压力将提高。初次游玩建议使用1×。”

验收标准：

1. 覆盖首次1×→2×、后续2×→3×→1×、重试、重启和规则页重读，按钮与实际倍率一致；首次说明关闭后保持2×，倍率只切换一次。
2. 说明打开、关闭及原有暂停／恢复状态正确；阅读期间不出兵、不攻击、不推进技能冷却、不计时、不发计时军饷，恢复后不补算。说明期间切后台或失焦时保持系统暂停，不自动恢复。
3. 在1280×720、1920×1080、2400×1080检查文案完整、无截字和遮挡，并在手机上验证阅读与关闭操作。
4. 首玩观察中，5名新玩家至少4名能说明“来敌与军饷加快，我方攻击和技能速度不变”，并理解高倍率会提高守关压力；此为建议的小样本通过线，尚未实测。
5. 领域规则、正常经济与成绩版本保持；全局同步快进属于未来独立设计，不纳入本项。

## 已认可新增改进：游戏UI精修（2026-11-19）

状态：用户已认可，待实施。本次只记录方向与验收，不代表运行时UI已修改或通过新验收。保留v3/v4及青绿纸面、宋体标题、名将插画方向。

| 优先级 | 方向 | 改进范围 |
| --- | --- | --- |
| P1 | 战斗信息层级 | 常态突出军饷、城防与当前操作；低城防、Boss临近时强化警示，路线说明和辅助统计保持次级，位置稳定 |
| P1 | 底部军令台 | 合并“已出阵1阶／已部署1阶”等重复信息；姓名、定位、费用或阶位及一个关键状态优先，保留清晰选中框 |
| P1 | 升级收益呈现 | 将真实新增或变化项置于主位，不变属性弱化；例如突出“枪线推退目标1→3名”，收益与费用、升级按钮相邻 |
| P1 | 手机阅读与点击 | 优先放大决策文字和热区，减少同屏辅助文字；截图检查与实际手机密度、握持、阅读和点击分别验收 |
| P2 | 敌我与危险辨识 | 用敌方底座边缘、小形状标记及行进方向增强辨识；保留清爽战场，不恢复大姓名牌，不只依赖颜色 |
| P2 | 选将信息结构 | 详情按核心用途、出手特点、成长变化分组；查看焦点用描边、加入名单用勾选徽记、进入沙盘用实心主按钮 |
| P2 | 军势状态层级 | 明确未成势、两人成势、四人升势；选中武将时强调对应阵营，减少反复阅读四条统计 |
| P2 | 选关与结算行动 | 强化首次推荐关卡；失败先呈现已有关键失守事实与一条可执行建议，普通统计次级，下一步操作明确 |
| P3 | 品牌识别 | 将现有“令”印章统一用于战役标题、弹窗和结算等适当位置，统一比例与字形，控制数量 |

首批集中精修战斗顶栏、底部军令台、右下升级区，并进行手机可读性验证；已认可的进军倍率说明沿用上一节条目。其余页面随后分批推进，不同时重排全部界面。

验收标准：

1. 覆盖正常战斗、备战空部署、选中与未选中、可招募／缺钱／已部署、可升级／满阶、暂停／恢复及胜败；同一状态的文字、颜色与操作一致。
2. 在1280×720、1920×1080、2400×1080及安全区场景检查无截字、重叠、遮挡与孤立标点。常用控件位置稳定，紧急警示不挤动其他控件。
3. 满10将、敌群与Boss警示同时出现时，重要预警仍优先；已有姓名牌遮挡修复、真实升阶首次施放强调与孤阵预览继续保留。升级成功、等待新阶施放、首次真实施放分别可辨，覆盖无目标、连续升阶、失败升级、暂停恢复、重开与预警竞争。
4. 升级面板只展示真实规则收益，能够区分新增能力、不变属性、满阶与军饷不足；不虚构组合归因、伤害或尚未生效的军势收益。
5. 选将的查看、加入名单、成长预览与进入沙盘可区分；军势的名单预计档与战中实际人数／孤阵生效状态不混淆。已有禁选Boss与10人上限保持。
6. 手机正常握持时能读出军饷缺口、军势状态和升级变化，补刘海／导航区、左右手遮挡检查；热区按设备密度检查，优先参考48dp。建议连续20次点击至少19次命中；此为待验证的建议通过线。
7. 建议5名新玩家至少4名能快速找到首战入口、说出升级的主要变化、指出选中守将与Boss，并在结算后明确下一步；记录完成时间、误点和口头求助，不以静态截图代替易用性通过。
8. UI精修保持领域规则、经济、实际时钟、存档和成绩版本；新增复盘事实或数据接口须按实际因果另行核对，不以装饰补造数据。提交前复跑对应规则、Unity布局与真实按钮流程，真机与人工体验单独记录。
9. 查看详情与切换成长预览不改变入队；加入／移出、满10人、禁选、推荐与清空后摘要同步。选关与结算覆盖无成绩、已有成绩及最终关无下一关，详情展开、重试和下一关导航正确。

## 用户反馈与目标

用户试玩青绿行军版本后反馈：“我试玩了一下感觉还行，就是解压的感觉还少一点，是不是可以通过增加数值或者特效以及优化武将之间的配合关系来提升玩家的游戏体验。”

体验目标：杂兵清得痛快，精英和Boss保留压力，武将配合能明显改变战局。延续“需要布阵，但打起来很爽”的方向；通过集中清兵、分层反馈和可理解的配合形成释放感，避免仅靠全体加攻消除布阵意义。

| 荀彧＋主力输出 | 合格友军命中触发协射，独立冷却1.5秒；二阶可改射，三阶两箭，不递归 | 独立弹道或短暂来源提示，让补箭、补刀可辨认 |

备选：貂蝉＋关羽。现有易伤持续2.5秒、承伤倍率1.25，同类不叠加；可先补易伤标记与命中反馈。

其他规则核对：曹操为范围增伤，一／二／三阶18%／21%／24%，不是攻速光环；三阶最多让3名友军追加普攻。陆逊已有受代数和目标数限制的燃烧传播。首轮无需铺满25将固定羁绊，也不引入无限递归触发。

配队必须遵守本关全部Boss禁选；黄巾实验前逐一核对目标关卡的组合合法性。虎牢合战可用上述三组，但该关吕布禁选，不作为己方配队示例。

## 已实现内容与当前缺口

- 已有持续快普攻和独立特色技能；普攻配置间隔约0.420～0.770秒，不再将“首次加快普攻”当作新工作。
- 黄巾第4～8波已有短批密集出兵，批内间隔0.55进军秒；新实验是在已有节奏上比较，不能描述成从零新增密集波次。
- 已有命中闪色、约0.24秒致命退场、攻击动作和真实攻击几何。已有连破在首个击退后的固定0.4秒窗口内累计，至少3次才显示，不是持续续时的长连击。
- `BattleEffects`对`notice`主要处理登场，连环传伤／补入和号令缺少专门反馈；荀彧协射与普通箭相近，易伤和连环缺少清楚状态显示。
- 当前`kill`事件没有攻击者身份，不能准确显示“某两将组合击破”。若未来需要归因统计或专属组合播报，应先设计真实因果数据，不能根据近邻武将推断。
- 现有效果预算为最多90特效、14数字，并有限频；后续沿用预算，优先保证Boss预警和重要操作可读。全屏白闪、持续震屏、强制慢放不作为默认方案。

## 规则、经济和记录边界

- 保持25将、战前最多10将、本关全部Boss禁选、每将每局最多招募一次。城防归零才失败，Boss突破扣15城防的现行规则保留。
- 1／2／3倍进军只加快敌军移动、出兵、波间等待和计时军饷；我方普攻、技能及状态时长按有效实秒。不能把倍率改成全局快进来制造爽感。
- 清兵、波次或等待变短，可能减少计时军饷；必须复核首次招募／升级时间和开局资金、计时收入、击破赏金、支出的完整账本。
- 实际更改平衡时，以当前`faction-army-v1`及后续实际冻结版本为准，`growth-tempo-v2`仅作历史参考；新竞速另带资格版本与独立入口。不混用不同平衡的最快成绩，不清除或伪迁旧纪录。
- 运行配置由生成工具生成；实际改配置时核对`tools/build_game_content.py`与`database.json`一致，避免只改生成结果后被覆盖。具体契约见[运行时契约](runtime-contract.md)。
