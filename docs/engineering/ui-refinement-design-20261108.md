# 界面精修设计

日期：2026-11-08。用户已批准上一轮评审，并授权助手制定计划、完成实现。

## 方案与范围

采用既有美术上的操作精修：保留深青、纸色、暖金、v3/v4人物与地图，只调整Presentation和编辑器验收。与纯换色相比，此方案直接处理判断与点击；与重做整套UI相比，可保留已确认的沙盘和规则坐标。

不修改Domain、25人配置、军饷、成长、速度、存档键、包名或原始素材。不安装依赖，不提交尚无初始提交的整个工作区，不覆盖既有安装包与交付目录。

## 战斗信息与操作
- 顶栏第一行强调关名、军饷、城防、实际用时；第二行保留波次和来敌预告。收入只显示按实际秒换算的当前值，完整口径和进军说明进入“规则”弹窗；切换倍率给短提示。
- 右上固定“开战／暂停／结算”入口，备战时金色并保持可用；右下专门显示招募／升级上下文。待部署的“取消选择”使用次级色；未选中时提示部署与使用右上开战，避免出现第二个主开战按钮。
- 详情与规则入口的热区达到至少104×88画布单位；选将加入按钮扩大到适合现有网格的88×88；阵位120×88热区抵消0.67地面纵缩，视觉底座保持地面透视。热区不得遮挡相邻控件或改变真实规则坐标。
- 默认阵位用较清晰的边线，部署／调位用较淡底色和符号，当前候选独立描边；减少全部阵位同亮的噪声。
- 当前级和下一级预览重合时不重复显示完全相同的射程环；成长变化保留准确文字。

## 选将与品牌层次
- 正在查看的武将用描边，已入阵用现有勾与底色，两个状态独立。
- 成长阶数明确选中态，查看不改变阵容，加入／移出保留独立按钮。
- 在既有卡片空间内提高可读字号与加入热区，避免内容重叠。
- 选关地图加大有效展示，保留本版最快、最近通关与旧版最快准确口径。主菜单和预览仅使用既有图片、阴影与布局改善层次。

## 结算与详情
- 有下一关的胜利以“下一关”为金色主按钮；失败以“重新推演”为主按钮。
- 本局结果、成绩状态优先，历史最佳快照与突破复盘放入可展开的详情区域，真实记录均可查看；保留已有命名以便自动验收。
- 详情阅读维持暂停语义，关闭恢复同一会话；展开不重开、不写玩家档。
