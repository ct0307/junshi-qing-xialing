# 完整流程与移动稳定性实施

沿用用户已批准的工程路线，补齐主菜单至结算、系统返回与移动稳定性的自动证据，不增加玩法规则或外部依赖。

- GameFlow负责页面、战斗、暂停和结算，公开只读CurrentSession/CurrentLevel及Tick、HandleBack、PauseForSystem入口。YanyiGame保留Unity启动、屏幕和系统回调。
- GameProgress封装通关读写与最佳城防，运行使用PlayerPrefs委托，检查使用字典；失败不保存，最佳纪录不下降。
- 备战返回显示离开确认，继续后保留部署和准备状态。失焦只暂停运行中的战斗，恢复前台不自动继续。错误页由平台保持，flow为空时返回不进入菜单。
- SafeAreaLayout应用现有等比缩放及居中偏移，参数化检查16:9、宽屏、非对称刘海与底部预留，以及零尺寸/无效区域回退。
- Unity真实按钮流程检查菜单、选将限制、备战取消、暂停、失焦幂等、重开、胜败、下一关与存档。图片覆盖菜单、选将、暂停和结算；不点击真实音效设置。
- 官渡/赤壁增加固定正常经济通关回归；数值保持不变，虎牢策略缺口如实记录，不伪称人工试玩。

交付验收：规则和内容检查、Unity流程与布局检查、Windows/Android重建及APK指纹/CRC/签名。手机系统事件投递、触控、实际安全区和性能仍待实体设备。
