# 美术精修样例：青绿微缩

用户选择精致2.5D国风微缩沙盘，延续既有青绿、纸色、暖金体系。样例采用已安装Unity离线渲染微缩几何体，导出2D地图与透明人物贴图；运行时仍可沿用现有uGUI，无需引入3D运行负担或新依赖。

## 方案选择

| 方式 | 取舍 |
| --- | --- |
| 在现有平面路径继续加细节 | 易保持一致，但体积和材质提升有限。 |
| Unity离线制作并渲染微缩几何体，推荐 | 统一真实受光、投影和材质；保留2D部署与移动管线；先用一图两将验证。 |
| 新绘厚涂贴图 | 上限高，当前缺内置生成工具；外部API需单独明确选择，不能静默调用。 |

## 样例目标

地图以黄巾郊野为首例。地形有边缘厚度，村舍、田埂、石块、林簇形成疏密，土路保持连续清楚。较高景物安排在边缘与非部署区域，不占用阵位或道路。采用左上暖光、较冷暗面、低反光草土和较清晰屋檐边缘。

关羽与赵云采用统一微缩雕像比例。重点塑造头部、肩甲、衣摆与兵器的整体体积，再加少量甲片、发须与边饰。关羽保留绿袍、重枣面、长髯与青龙偃月刀；赵云保留银盔、白袍、长枪。二者共享受光方向与台座规格，材料反射区分皮肤、布、金属，不靠密集纹样堆砌。

## 文件与实现计划

- 新增 `tools/artlab/` 中的共享网格／材质、人物、地图及离屏渲染C#脚本，源码不进入正式UnityGame。
- 新增 `tools/Render-ArtSamples.ps1`，在忽略的独立ArtLab工程使用现有Unity工具链渲染；不安装工具或第三方包。
- 新增 `docs/ui/art-refinement-v5/` 下的样例地图、透明棋子、对比图、规格与验证清单。v3/v4源稿和运行时图不覆盖。
- 地图1920×1080，保持黄巾正式路线／阵位坐标；人物768×768，台座中心继续使用(360,660)。
- 视觉复核同时查看原尺寸与游戏内约113／170像素显示大小。检查透明边缘、足点、道路中心线、阵位清空及沙盘裁剪。
- 样稿属于离线渲染／静态合成，必须明确标注；正式接入与新包不引用旧UI精修版的验收结果。

## 范围边界

本阶段不修改Domain、数值、配置、存档、UI结构或现有试玩包；不把渲染样例称为全部25将或5张地图已完成。先以视觉结果确认此管线能显著改善粗糙感，再扩展正式内容。

## 首批样例实施结果（2026-11-08）

当前版本为[v03样稿](../ui/art-refinement-v5/README.md)，完成黄巾地图、关羽和赵云及6张PNG对比／静态合成。工具位于 `tools/artlab/`、`tools/Render-ArtSamples.ps1` 和 `tools/compose_art_samples.py`，使用独立ArtLab工程及现有Unity，不安装新依赖。

Unity渲染退出0，人物足点和地图参考坐标断言通过；地图原样读取正式70路线采样点及32阵位。图片规格、透明安全边、异常紫红及输入文件哈希检查通过，正式工程407个登记文件与UI精修版基线一致。

独立复审已查看原图、对比板和1280静态合成，未发现阻挡方向样稿展示的P1／P2。仍保留人物眼神偏玩偶、视线略向下以及地图中央地表偏均匀两项P3，后续继续精修；本轮不作商业美术定稿判断。

v01因赵云台座材质失效、地图过曝及人物细节问题被拒绝，v02为中间检查稿，v03为最新展示样稿。原素材及试玩包仍为上一轮UI版，未开展新美术正式场景、Windows／Android运行或手机验证。后续先吸收具体视觉反馈、接入首关取得真实证据，再扩展其他角色与地图。
