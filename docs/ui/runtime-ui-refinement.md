# 运行界面精修

沿用已确认的v3青绿沙盘与v4人物，不重绘源稿。服务于横屏塔防的即时判断：看清敌我、选择阵位、识别费用和升级状态。

| 优先级 | 调整 | 验收 |
|---|---|---|
| P1 | 战场地面统一纵向收拢，为顶部棋子留出完整轮廓；棋子和名签保持比例 | 五关每个阵位上的190宽棋子和独立名签均处于顶栏与操作区之间 |
| P1 | 说明进入底部详情，短消息进入固定状态条 | 技能长句不覆盖道路；未选将、已选将、已部署均有操作指引 |
| P1 | 姓名与等级分开 | 诸葛亮、孙尚香等三字姓名及1～3阶完整显示 |
| P2 | 六卡一屏，头像、姓名、定位、费用和状态有固定位置 | 已出阵、可招募、军饷不足、选中均有文字区分 |
| P2 | 普通阵位弱化，选将后强调；射程环减淡 | 底座不抢人物；显示变换不改变规则距离 |
| P2 | 升级显示价格和差额，满级使用明确状态 | 军饷不足和已满级可解释，不误导为可升级 |

配色沿用深青183F38、底青123B33、纸色EFE8CD、暖金D8BC7A；次要文字使用更清晰的浅青和墨青。标题32～42、卡名26、说明及状态20～23；不新增字体和依赖。

实现只作用于Presentation：地图地面、阵位、射程和特效在统一战场容器中变换；人物子层抵消纵缩放。Domain配置、战斗距离、道路和阵位数量不变。地图原图含边框，运行时截取内侧并绘制独立边框，使顶部留白与战场成为同一块沙盘。

验证：现有50项规则测试、资源verify-only、Unity配置及字形检查；新增五关布局边界检查及真实按钮回调检查。按照用户要求，优先使用Unity内部自动验证，无需Computer Use。Windows人工输入和手机触控不以离屏渲染替代。
