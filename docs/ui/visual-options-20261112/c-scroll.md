# C · 丹青游记

用一本横向展开的山河军图承载守城：地图几乎无框，战报像页边批注，五名武将排成册页，右下圆形朱印下达开战军令。湖蓝细线与清楚的中文状态保证它首先是横屏塔防操作界面。

本页是可点击的界面提案，地图、战场人物与头像沿用正式游戏资源。没有完成新美术重绘，没有接入真实战斗，也未进行 Unity 或真机验证。

## 视觉规范

| 用途 | 色名 | 色值 |
| --- | --- | --- |
| 画板与轻纸纹 | 浅纸 | `#F2F4EA` |
| 册页与浅底标签 | 玉版纸 | `#FCFDF6` |
| 选中、空阵位、页边标注 | 湖蓝 | `#397B8C` |
| 已上阵、正常军饷 | 竹青 | `#4D725D` |
| 主操作、军饷不足 | 矿物朱 | `#B74637` |
| 正文与地图姓名 | 细墨 | `#263E42` |

标题、武将姓名与圆形军令优先使用系统宋体 `SimSun`；仅在这些短标题使用书册笔意。随资源提供的 `chinese.otf` 实际为 `Noto Sans CJK SC`，用于缺少宋体时的中文后备。说明、按钮、数值用 `Microsoft YaHei UI / Microsoft YaHei`，保证小字与数字清楚。关卡标题 31px，武将姓名 21px，军令 24px，关键数字 23px，招募费用与顶部操作 16px，布阵提示与选择操作 14px，定位及部署状态 12px。10px及以下只用于非操作性的细小题注和来源标记。数字使用等宽数字特性。

## 布局与记忆点

- 固定逻辑画板 1280×720，由公共脚本按可用空间等比缩放。
- 地图位于 `(30,94)`，尺寸 `1220×462`，完整呈现同一正式地图及 32 个真实阵位。地图保留画面体量，不使用侧边控制台，也不叠加大块面板。
- 普通空阵位采用约7%透明度的浅草色填充与低对比竹青细线，不以亮白椭圆铺满战场；仅候选阵位强化湖蓝轮廓与浅青填充，悬停和焦点再显示操作反馈。
- 顶部左侧是关卡与细小“山河军图”书签，右侧是波次、城防、军饷与倍速、规则入口。规则与右下开战主操作使用不同名称，避免语义混淆。
- 地图下方一行呈现当前武将、定位、费用、布阵提示、取消选择与升级。将“选择武将”和“点击阵位招募”分成明确的两步。
- 五将横册位于底部 `(23,590)`，尺寸 `1066×107`；细页缝、轻薄纸边与选中书签构成书册感，头像与姓名均可辨识。
- 右下朱印有 105×105px 的真实按钮热区和“开始守关 / 暂停 / 继续”文字。以印章表达下令，是本方案唯一强烈装饰焦点。
- 纸纹为低透明度细纹，不压到地图人物上；不使用污迹、密集花纹和大面积褐色做旧。

## 可点击状态

| 状态 | 视觉与行为 |
| --- | --- |
| 初始备战 | 军饷240，关羽与黄忠已上阵，选中赵云；空阵位可点击招募。 |
| 可招募 | 头像、定位、费用与“可招募”保留正常对比；选择后湖蓝细框与书签出现，仍需点空阵位才招募。 |
| 已上阵 | 竹青“已上阵”文字与勾选标记；点击武将进入查看，避免误认为可重复招募。 |
| 军饷不足 | 公共钱包切换为24时，未部署武将显示“不足”文字，费用与提示用矿物朱；不只靠颜色传达。 |
| 未选将 | 公共取消选择操作更新说明，阵位提示引导先选武将。 |
| 运行 / 暂停 | 公共状态更新页边状态、计时与朱印文字；暂停时状态转朱，继续按钮转湖蓝。 |
| 成长查看 | 独立文字按钮位于选择信息行右侧；本页仅预览成长入口与武将说明，不模拟升级规则或计算升级费用。正式接入时读取现有Domain。 |
| 结算 | 公共预览结算覆盖层展示演示结果；不写入玩家记录，不把演示视为实际通关。 |
| 键盘焦点 | 所有按钮有矿物朱 3px 外轮廓；减少动态偏好关闭悬停位移。 |

## 正式美术真正重绘的要求

地图需按原路点和 32 阵位净空重绘为有体积的国风手绘田园。道路应有可读的厚度、路肩和连续转折；农田、林木、坡地与关楼形成疏密和前中后景，不以平面色块或纸纹代替形体。湖蓝与竹青只帮助色彩统一，战斗单位和阵位必须比地面更容易辨认。

武将需以现有角色身份为基础重新绘制神态、衣料、皮革和金属。保留关羽的长髯、青龙刀与绿袍轮廓，黄忠的老将面貌与长弓，赵云的银甲与红缨枪，周瑜和陆逊各自的冠服及姿态。统一战场人物的足点、视角与轮廓粗细；头像和战场小人应共享五官、衣甲设定。当前页面只沿用已有素材，不能据此登记重绘完成。

## 取舍与后续验收

以纸面留白和书册选将换取轻盈、可亲近的横屏体验；不加入角色稀有度、付费货币或可手动释放的大招。相比厚重军令台，常驻说明更少，所以当前武将、费用与“点阵位”提示必须持续清楚。横屏缩放时所有逻辑位置保持稳定；手机可读性与触控尺寸需在后续 Unity 实机另行验收。
