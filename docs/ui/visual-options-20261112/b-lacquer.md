# B · 漆金军令

以军令牌的侧边名册组织操作，用黑褐漆面承托明亮军图。最醒目的操作是右上方朱漆「开始守关」；开始、暂停与继续始终占据同一位置。细铜边、字距与留白负责质感，金色只标记当前选择、军饷和关键动作。

本提案为可点击 HTML 设计比较，沿用正式地图与武将素材。不是美术重绘交付，也不是 Unity 运行结果。

## 色彩

| 用途 | 色值 | 使用范围 |
|---|---|---|
| 黑褐漆面 | `#211C18` | 主控制面、画板底色 |
| 漆面起伏 | `#302821` | 侧册与局部层次 |
| 青铜边缘 | `#756654` | 细分隔、安静边框、辅助线 |
| 深朱军令 | `#8D352D` | 主军令按钮、操作提示小印 |
| 旧金 | `#C7AB70` | 当前武将、军饷、关键焦点 |
| 象牙白 | `#EEE4D0` | 标题、数值与主要正文 |

上述六色组成 UI 主色；已上阵以克制灰绿辅助识别，缺饷以浅朱文字提示。战场保留原图亮度，仅降低少量饱和度，没有暗色覆盖层。

城防位于标题与军饷之间，沿用资源区20px等宽数值字级，静态显示 `30/30`。共享界面演示不扣血，缺饷状态也不会改变城防颜色或数值；已有军饷、波次与主军令的位置保持稳定。

## 取舍

- 与上下双栏方案拉开结构差异，左侧常驻名册占用200px横向空间；换来稳定的逐将查看与较少的横向扫视。
- 战场保持原图比例和完整32阵位，不用黑色滤镜营造漆金感；深色材质集中在UI区域。
- 成长令带只保留当前武将与强化，避免把新技能、装备或不存在的战术系统塞入底部。
- 全局仅一处高对比朱漆主按钮；名册选择和强化使用更安静的金线，减少多处争夺视线。
- 原生DOM、共享脚本和本地资产便于直接比较；Unity适配、实际战斗反馈与Android触控仍需后续单独验证。
