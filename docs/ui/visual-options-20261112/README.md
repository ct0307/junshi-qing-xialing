## 美术交付边界

- 当前会话没有可调用的内置图片生成工具；没有擅自使用图片API、处理密钥或安装依赖。
- 地图与五将立绘／头像沿用正式游戏素材。三案展示了新的UI、字级、配色、材质表达和状态设计；**没有完成三套新地图或新人物绘制**。
- 后续地图／人物的造型、笔触、地表、路肩与材质要求分别写入三份规格。现有地图调色或界面换肤不视为重绘完成。
- 共用黄巾关70路点、32阵位及关羽／黄忠／赵云／周瑜／陆逊。初始以内部阵位29／30展示两位守将，候选31。上沿阵位人物在预览中按边界缩小以完整显示，足点不移动；实际游戏并未修改人物比例。
- 浏览器交互只演示状态，战报是明确标注的示意数据，计时保持示意值；不运行真实战斗、不模拟升级数值、不写玩家记录。每个方案保留规则入口与主操作的清楚名称。
- 中文字体为项目已有Noto Sans CJK SC，许可随 [assets/OFL.txt](assets/OFL.txt) 一并保留；宋体标题依赖系统字体回退。

## 本轮实际验证

三案均已在真实浏览器中验证，详细输出见 [browser-checks.json](browser-checks.json)。

| 验证 | 实际结果 |
| --- | --- |
| 基础资源与内容 | 各32阵位、五名候选；1280与1920画面图片均加载，无缺失素材。 |
| 招募 | 选赵云、点阵位31：军饷240→120，状态变为已上阵。 |
| 调位 | 再点空阵位32：显示免费调位，余额保持120，不重复招募。 |
| 缺钱 | 余额120选周瑜135，点空阵位：明确还差15；陆逊115仍可招募。三份缺钱截图独立留档。 |
| 未选将 | 清空选择后，成长操作禁用，并给出先选择武将的提示。 |
| 运行与规则 | 开始、暂停、继续可切换；打开规则暂停当前预览，关闭后恢复原运行状态。 |
| 对比页 | A／B／C切换、军饷24、未选将、战报示意均可操作。 |
| 尺寸 | 三套1280×720、1920×1080；390×844对比页未横向溢出。手机竖屏只用于方案浏览，正式游戏仍横屏。 |
| 上沿人物 | C方案1920下实际招募顶部阵位1，人物完整位于地图容器内。 |

根任务实际查看三套常规PNG；独立复审实际查看六张常规／缺钱PNG，没有发现P1，提出的C规则入口语义混淆P2已修正并重新点击验证。A／C低对比阵位与B部分辅助小字仍是后续实机P3复核项。没有将技术验证当作用户审美认可。

资源缺失的错误提示已实现，但本轮没有在浏览器中模拟资源丢失；Unity、APK、手机、真实性能和存档均不在本轮验证范围。

## 素材保护与复现

[asset-manifest.json](asset-manifest.json)登记提案资源副本与输入哈希；[verification.json](verification.json)记录最终PNG解码与正式工程407文件指纹核验。只新增本设计目录与 `.planning/visual-options-20261112/`，不替换正式素材、配置、源码或既有游戏包。

`prepare_assets.py`只可在新的独立目录首次准备资源，已有assets时会拒绝覆盖。`finalize_gallery.py`仅在本提案目录生成总览与校验记录。预览不依赖第三方npm包、网络CDN或后端。
