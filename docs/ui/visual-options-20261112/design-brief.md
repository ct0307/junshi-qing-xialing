# 军师请下令 · 三套视觉提案

这是黄巾关的美术方向与UI设计提案。地图与武将来自当前正式游戏；本轮对布局、字级、层级、材质和交互进行可视化设计，不将沿用素材称为重绘完成。

## A 青绿行军
以青玉、竹叶、浅绢和暖铜建立明亮的行军感。地图保持最大面积，所有重操作收在上下边缘。数值使用清晰等宽数字，关卡标题少量采用宋体。主操作独立于阵位选择，玩家始终知道下一步。

地图重绘强调起伏连续草土、自然路肩、小簇田树与守城关楼焦点；原有70路点和32阵位净空不变。人物使用清楚衣甲材质、克制描边和统一足点；需要真正重绘而非色块描摹。

## B 漆金军令
从三国军令牌与漆器取材，用黑褐、青铜、深朱与旧金组织控制。采用侧边军令面板与大地图形成不对称构图，资源、进军、暂停保持稳定位置。文字与按钮对比清楚，金色只用于关键状态。

地图重绘为明亮但低饱和的山河军图，草土与石木有完整形体，人物衣甲质感更精细。黑金只用于UI，不将整张战场压暗。高级感来自结构和材质，避免满屏花纹。

## C 丹青游记
以浅纸、湖蓝、竹青、矿物朱建立轻盈的手绘感。选将如横向展开的武将册，战斗信息像清楚的页边批注。圆形朱印主操作、细墨标题和纸面分层构成记忆点，装饰集中在边角。

地图重绘采用有体积的国风手绘田园，前中后景有疏密、道路有真实厚度和转折，纸纹不能影响单位辨识。武将神态鲜明、衣甲有软硬区别，保持关羽长髯和赵云红缨枪等身份轮廓。

## 共用交互要求
- 同一黄巾关地图、32阵位与五名候选，避免用更热闹的战况制造比较优势。
- 至少覆盖备战、运行、暂停、未选将、军饷不足与结算的界面样态。
- 查看与上阵区分；已上阵、可招募、资金不足有明确文字和状态。
- 文案使用真实游戏概念，不添加不存在的可释放大招、付费货币或角色稀有度。
- 预览与正式游戏隔离，不存玩家记录，不接入真实战斗。
