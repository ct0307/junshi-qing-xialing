# 素材精修：青绿演武

以 v3 的青绿沙盘为骨架，保持舒展的空间和清晰的战斗阅读顺序。人物、敌军与浅色关道形成明确层次，细节只服务于身份辨认和材质表达。精工应体现在轮廓、转折与留白之间，而非图案的数量。

光线来自左上方。脸部以柔和的额头、鼻梁与颧骨受光塑造体积，衣甲用窄高光和接触暗面表达厚度，织物用顺着折叠的明暗表现重量。金属、皮革与布料具有不同的边缘和反光强度，使小尺寸人物仍能分清兵器与身体。

以原著描写引导人物神态和辨识特征。关羽重枣面与长髯、张飞环眼虎须、赵云宽阔面形、周瑜清俊面容各有侧重；诸葛亮、黄忠与吕布的冠服和年龄表达延续已有依据。材质刻画与神态属于原创美术转译，详细出处沿用第三稿说明。

山壁的裂隙与草坡沿石块结构分布，关楼的瓦檐、木构和门洞具有真实的前后关系。建筑细节经过克制的取舍，把精度留在交汇点与轮廓上，让道路、阵位和角色继续主导画面。

动态反馈采用短促、收敛的笔触和柔和外沿：招募从阵位扩散，刀光顺攻击方向掠过，火攻由地表升起，敌将预警贴近脚下。动效在需要时清楚出现，结束时回到干净沙盘；最终时序和强度需在手机工程中校准。
