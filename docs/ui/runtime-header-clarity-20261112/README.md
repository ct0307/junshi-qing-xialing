# 战斗顶栏信息重排

用户指出顶栏杂乱，上一轮字体与形状精修没有解决信息分组。复查发现原收入框与战况标题纵向相交，关卡阶段、波次与敌情也没有统一阅读基线。本轮仅重排176逻辑像素高的顶栏。

| 优先级 | 问题 | 本次调整 |
| --- | --- | --- |
| P1 | 收入与战况文字框相交 | 收入放回军饷数值右侧，与资源同行 |
| P2 | 关卡阶段、波次与敌情混成多行 | 主行放关卡、阶段、资源、时间和操作；第二行放波次、波名、敌情和计数 |
| P2 | Boss出现后阅读位置变化 | 复用第二行槽位，预警显示在敌情位置，生命数字及生命条在右侧 |
| P2 | 低城防与损失占用不明确 | 将状态、损失与城防数值放在同组，保留真实刷新 |

第一行与第二行之间有留白和淡分隔线；规则入口简化为“规则”，完整规则仍在原弹窗。保留A方案字体、配色、地图、人物、底部和玩法。

## 验证证据

`./tools/Build-Game.ps1 -Target Header` 最终退出0，输出172张真实Unity截图，涵盖1280×720、1920×1080、2400×1080。新结构检查覆盖五关备战、开战和三倍进军的真实文字：字形完整、单行、文本框不重叠、同行间隙至少6逻辑像素、两行间隙至少12逻辑像素。

同时保留完整交互回归：招募、升级、分页、规则暂停恢复、黄巾胜败、Boss突破继续守关、成长与预支军饷、完整导航和隔离存档。实看普通战斗、空阵布阵、Boss预警、低城防和宽屏；自动检查通过只代表布局与交互符合检查条件，视觉选择仍以用户反馈为准。

独立视觉及代码复审未发现新的P1/P2。复审确认旧版的基线与分组问题已改善，低城防与损失仍能沿城防组阅读。验收边界：新增几何间隙断言覆盖五关初始状态；Boss与低城防由现有字形检查和截图覆盖，最长混合敌型尚未单独截图实看。
