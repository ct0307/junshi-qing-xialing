# 演义美术第三稿：人物容貌与虎牢关

## 本轮目标

保留第二稿的青绿微缩沙盘与信息层级，依据《三国演义》的人物文字调整五官与神情，依据战役场景建立地图结构。原稿不覆盖；本轮输出是静态概念，并非 Android 运行截图。

## 人物依据与美术转译

以下短引文依据维基文库公共领域通行本，原文繁体，表中做简体转写；不同版本的字形与标点可能不同。

| 人物 | 原著已核对的依据 | 本稿处理 | 属于美术改编的部分 |
|------|------------------|----------|--------------------|
| 关羽 | 第1回：“面如重枣”“丹凤眼，卧蚕眉”，并写长髯 | 枣红面、狭长眼、厚眉、长须、威严神态 | 五官具体比例、绿色甲袍与木雕材质 |
| 张飞 | 第1回：“豹头环眼，燕颔虎须” | 宽阔脸、圆睁眼、重眉、浓密短须 | 具体肤色、盔甲与表情幅度 |
| 赵云 | 第7回：“浓眉大眼，阔面重颐，威风凛凛” | 年轻而宽厚的脸、较明显下颌、果断目光 | 银盔白甲沿用通行视觉印象，不声称来自这段文字 |
| 周瑜 | 第15回：“姿质风流，仪容秀丽” | 俊秀面容、清朗目光、与猛将不同的眉眼 | 无须、具体脸型、红披风和甲色 |
| 诸葛亮 | 第38回：“面如冠玉，头戴纶巾，身披鹤氅” | 清雅长脸、纶巾、从容睁眼 | 三绺须、具体服装配色与扇子造型 |
| 吕布 | 第5回：三叉束发紫金冠、红锦百花袍、兽面吞头连环铠，并写画戟、赤兔 | 紫金束发冠、红袍、兽面胸甲、画戟、锐利目光 | 该段未细写五官；双翎和具体面部设计为美术取法。本稿是人形棋子，未绘骑乘动作 |
| 黄忠 | 第53回：“虽今年近六旬，却有万夫不当之勇” | 老将面容、克制皱纹与锐利眼神 | 本次核对的段落未明确白须，白髯作为年龄视觉化处理 |

神态是对人物气质的美术解释。原著五官描写、通行形象与游戏材质三者分开记录，避免把每个造型细节都归为原文。

## 虎牢关场景依据

第5回写到“这关离洛阳五十里”“去关前扎住大寨”“卓自在关上屯住”等，并有“关上西风飘动青罗伞盖”的描写。它支持关城、关前营寨、交战地与旗帜的空间层级；没有给出能直接作为游戏关卡使用的完整地形图。

本稿采用关前两路接近、山口汇合、关城嵌入岩壁的布局。山形、军营位置、道路弯曲与宽度、34 个固定阵位都是为塔防作出的比例和结构改编，不是考古复原或原著地图测绘。

玩家守关、跨阵营调遣武将与敌将进攻的关系属于“演义沙盘”演武规则，也不宣称逐场复现原著交战双方与胜负。

## 后续地图应采用的地点特征

| 参考地点 | 应优先表达的场景特征 | 关卡设计方向 |

| 虎牢关 | 关城、关前营寨、通向关口的道路 | 合流与山口火力覆盖 |
| 长坂坡／长坂桥 | 坡路、桥口、追兵与断后 | 桥口控制与远端补漏 |
| 赤壁 | 江岸、战船、营寨与火攻 | 岸线分工、火攻和船队路线 |
| 官渡／乌巢 | 营垒、粮草据点与进军道路 | 分路防守与补给取舍 |

本表是后续地图美术与机制的候选方向，不代表本轮已经完成五张地图。
