# 演义沙盘 v4 美术素材

此目录是可供后续开发使用的素材交付，不是 Android 工程。当前精修七位示范人物、虎牢关与四类反馈；25 人角色池尚未全部制作。

## 素材结构

| 目录 | 内容 | 输出规格 |
|---|---|---|
| characters | 关羽、张飞、赵云、周瑜、诸葛亮、黄忠、吕布 | 7 张，768 × 768，透明全身棋子 |
| portraits | 同七位人物的头像 | 7 张，320 × 320，透明上半身裁剪 |
| maps | 虎牢关背景，含道路、空阵位和建筑，不含人物与界面 | 1 张，1920 × 1080 |
| buildings | 独立关楼、营帐 | 512 × 512、256 × 256，透明 |
| effects | 招募、刀光、火攻、敌将预警 | 各 8 张 256 × 256 透明帧，另附横向图集 |
| manifest.json | 逐文件尺寸、校验值、坐标及序列参数 | UTF-8 JSON |

共 53 张 PNG：14 张人物与头像、1 张地图、2 张建筑、32 张反馈单帧、4 张序列图集。展示板与战斗预览位于上一级目录，不计入这 53 张素材。

## 导入和对齐

- 人物、建筑与图集使用小写英文名称，单帧以两位数字编号。可按当前结构放入 Android assets；若单帧改放 res/drawable，需改为带字母前缀的资源名，例如 recruit_00.png。
- 人物为固定方形画布；768 图中的 `(360, 660)` 为台座对齐点，对应 320 设计坐标中的 `(150, 275)`。以此点对齐阵位，不要直接用图片底边对齐。若裁掉透明留白，需同步更新锚点。
- 地图采用 1920 × 1080 的逻辑坐标，实际显示等比缩放。manifest 保存 30 个空阵位与 4 个已部署位置，不能把这张图当成触控命中区域。
- 建筑提供独立素材，地图中已合成同源建筑；使用完整背景时不要重复叠加。
- PNG 使用普通 RGBA 透明通道；纹理过滤采用线性过滤、边缘钳制。Android Bitmap 通常会在解码时自动预乘透明度，不要再手工重复预乘。
- 图集从左到右读取八帧，单帧矩形为 `(帧号 × 256, 0, 256, 256)`。原点在左上角。各序列的锚点写在 manifest 中，均以单帧坐标计。

## 反馈时序建议

| 反馈 | 时长 | 播放方式 | 接入时机 |
|---|---|---|---|
| 招募入阵 | 480 ms | 单次 | 招募实际成功后，于阵位处播放 |
| 青龙斩击 | 240 ms | 单次 | 关羽攻击命中时，与伤害事件对齐 |
| 火攻余焰 | 640 ms | 循环 | 持续火攻区域有效时，结束后停止 |
| 敌将入场 | 800 ms | 单次 | Boss 出场时，于脚下播放 |

以上为初始美术时序建议。序列素材已准备，动态尚未接入游戏，也没有完成手机上的帧率、阅读性或触控实测。受击闪白、按钮按压、升级弹动等适合程序实现，避免为简单缩放与透明度动画额外保存大量图片。暂停时序需跟随游戏状态。

## 生成和追溯

使用已有 Python/Pillow 运行 `export_art_v4.py` 导出素材，运行 `render_concept_v4.py` 合成独立战斗图。不需要安装新依赖。导出前后均核对 v3 两张基准图的 SHA-256。

全部人物和建筑由本项目的可编辑绘图脚本生成。原著特征与美术改编的界限见 `literary-art-direction-v3.md`；系统字体只用于展示板渲染，未复制分发字体文件。
