# UI 视觉方向：青绿演武

## 视觉原则

青绿地形承托微缩棋子，画面首先传达一座可以亲手布置的小沙盘。道路、阵位和城池构成清晰的空间关系；山石、植被与城墙集中在边缘，细致处理转角、轮廓和材质，让有限元素也有完成度。

界面采用浅色面板与深青文字。青绿承担主要操作与己方识别，朱砂仅用于敌军和威胁，沙色自然成为行进道路。精确调整同一色系的明度与留白，避免用大量独立颜色争夺注意力。

人物依靠冠帽、兵器、服装与轮廓区分。棋子拥有统一比例、底座、光源和描边，关羽长刀、张飞长矛、黄忠弓与周瑜佩剑保留各自特征。原型人物图形是风格占位，正式资源需要继续精修并保持同一绘制规范。

标题适度使用楷意字形，正文和数字保持清晰。对齐、间距、按钮尺寸、选中与不可用状态需要逐项打磨；装饰服从信息层级。战场、人物、敌将威胁和当前操作依次成为视线焦点。

视觉记忆点是浅青色沙盘上的微缩名将与小军旗。动态只强化命中、部署、选中和 Boss 预告，反馈短促，避免遮住路线。最终美观程度应通过实际画面审阅和手机显示验证，不能仅由配色说明判定。

| 玉青：己方与选中 | #4E8B70 |
| 浅草：沙盘地形 | #DCE6CB |
| 沙路：敌军路线 | #DDC69B |
| 纸白：界面面板 | #F6F4EC |
| 朱砂：敌军与警示 | #B95446 |

- 标题：静态稿使用本机楷体；正文使用微软雅黑，数字使用 Segoe UI。这里只渲染效果图，不将系统字体文件复制或分发到游戏。
- 布局：以横屏 1600×900 制作概念图；横屏仍属当前设计建议，不等于用户已最终确定。
- 顶部：章节、军饷、城池耐久、波次与暂停。
- 中部：战场与 34 个阵位；空位淡显，选中武将显示覆盖范围。
- 底部：本局共 10 名角色，静态稿展示前 6 名，通过翻页或滑动查看其余人物；右侧保留选中武将的升级操作。
- 情境：虎牢合战中场迎战张辽，最终 Boss 为吕布；二人不出现在己方阵容。
- 图中状态与价格仅用于视觉演示，尚未经过战斗平衡验证。

## 验证边界

这是静态视觉概念图，不是运行截图。后续需在 Android 原型中验证点击面积、字体大小、屏幕比例、系统安全区域、动态特效与帧率。
