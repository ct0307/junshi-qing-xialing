# Boss突破容错运行时验收

本目录由 `UiBossBreachChecks` 通过真实 `GameFlow`、`BattleView`、uGUI按钮和战斗时钟采集。截图尺寸为1920×1080、1280×720、2400×1080；每次截图前检查所有可见文字的字形顶点与文本框高度。

## 夹具边界

- 运行时内容先深拷贝；不改写正式配置和历史视觉稿。
- Boss采用正式张辽的生命、速度、技能、护甲、抵城伤害和赏金。短路线为42单位，城防30，初始军饷1000、无自动收入；没有通过改血量或全图火力制造结果。
- 非致命案例在下一波前留8秒，检查突破后继续运行、真实暂停与恢复、按原费用招募吕布和升级。
- 末波案例仅有一名Boss，自然抵城后以剩余15城防胜利。二次突破案例有两名间隔4秒的Boss。低城防案例从13城防开始，验证归零截断。
- 这些是隔离规则与展示夹具，不代表正式关卡难度、实际通关策略或平衡结论。原全Boss击退参考检查继续保留。
- 游戏进度仅保存在验收场景的内存字典，不写玩家进度。

## 断言与截图

| 文件前缀 | 行为断言 |
| --- | --- |
| `first-breach-continues` | 首次Boss自然突破，仍运行且城防15；提示实际损失与继续规则，无提前结算 |
| `after-breach-paused` | 点击真实暂停按钮，战斗时钟和军饷冻结；可继续守关 |
