通过 `./tools/Build-Game.ps1 -Target Ui` 使用真实uGUI组件、按钮回调和离屏相机验证。主菜单、暂停页各输出1920×1080、1280×720、2400×1080，共6张PNG；主任务已逐张查看，设置文字与按钮无明显裁切。

检查包括音乐／音效独立开关、±10%音量、隔离存储重读、完成按钮、返回层级、暂停不恢复战斗、双系统挂起原因与前台不自动继续。选将满10人或点击本关禁选敌将时使用拒绝声，合法选将使用点击声，单操作不叠播两种声音。
