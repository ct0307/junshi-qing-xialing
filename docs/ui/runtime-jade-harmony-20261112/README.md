# A方案：字体与界面协调精修

根据用户“字体和其他方面不协调”的反馈，在已选A「青绿行军」方向内精修。本目录保留正式Unity运行证据，上一版runtime-jade-a-20261112完整保留。

## 改动

| 项目 | 本次调整 |
| --- | --- |
| 标题与姓名 | 思源宋体CN Medium；关卡42、将牌姓名32、成长标题28逻辑字号 |
| 操作与说明 | 保留原Noto Sans CJK SC；正文20–24，关键状态18以上逻辑字号 |
| 控件形状 | 将牌、按钮、状态签、人物名签和阶位统一直边细框 |
| 将牌比例 | 每张由222拓宽为266逻辑像素，移除头像后的独立底块 |
| 成长区 | 由536收窄为408逻辑像素，给五将姓名和定位留空间 |
| 分页与提示 | 分页移至将册标题行；常驻提示仅说明当前动作，重要战况与教学逻辑保留 |
| 规则与详情 | 浅绢面板、宋体标题、深色正文、青玉动作，与战斗页统一 |

画布为1920×1080；1280屏下所有尺寸等比缩放。人物造型、地图投影、阵位坐标、Domain、经济与存档没有调整。

## 字体

新增Adobe原版Source Han Serif CN Medium 2.003，字体文件未改写；经jsDelivr从Adobe官方仓库分发取得。随附SIL OFL1.1许可、原始路径、版本、字体元数据及SHA256，记录位于工程Fonts/ChineseDisplay-source.json。没有把系统宋体复制到安装包，也未安装新软件包。
