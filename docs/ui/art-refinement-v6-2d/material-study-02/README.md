## 与v07的差别

地面采用正式原图使用的连续低频底材和暖色洗染，不清空阵位周围的底材变化。作物改用有宽度的叶和谷粒，不再先画封闭高亮田板。第一次实验仍有完整土垄底座、重复麦穗和等距路肩；第二次针对精修将土垄打断，增加穗向、高度和前排空隙，减少规则草齿。

独立目视复核确认上述三点均有缓解。仍然存在黄色线束过密、前后层次不足、零散土斑偏符号化，以及道路长边偏直的问题。人物未重画，完整战场未接入，也没有新Unity运行、构建或手机验证。

## 复现

在仓库根目录使用现有Python及Pillow运行 `tools/art2d/material_study.py --output 新的实验目录名`。命令拒绝覆盖已有目录。`source.py`是本次源码快照；如需使用快照，应先复制到工程中另一份同结构的工具路径，再运行。样稿不包含或调用付费图片API，不安装依赖。
