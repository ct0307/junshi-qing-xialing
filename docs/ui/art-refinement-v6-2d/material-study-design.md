# 连续乡野

地表是一片连续的乡野，明暗来自土壤干湿与草叶疏密。保留原版青绿和暖土的关系，让缓慢变化穿过整个场地；阵位只限制实体景物，不切断底材的颜色。细致处理接壤处，使土地先成立，再承载农景。

谷穗和叶丛用各自的轮廓占据空间。前排遮住后排根部，金穗朝向各有偏差，菜叶以宽面接住光。以经过推敲的群组代替统一田板，裸土从根部间隙露出，田界随植物自然断开。

土路具有安静、通透的中间通行面。路肩通过草根与土层咬合，轮廓有节奏地断续；浅磨损沿地势延展，不排列成重复印章。每一处细节都服务于同一地面，避免把材料画成孤立贴片。

取舍以实际显示尺寸为依据。缩小后仍可读的叶群与穗丛是主要层次，细线只辅助表达。精修集中在边缘、遮挡和相邻材质的关系，完成度依赖逐处检查，不能靠增加物件数量代替。

本文件描述局部实验的判断依据，不表示结果已达目标；不重画完整战场或人物。
