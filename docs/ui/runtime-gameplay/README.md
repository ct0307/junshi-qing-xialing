# 玩法入门与布阵纠错画面验收

本轮使用 `./tools/Build-Game.ps1 -Target Ui` 验证真实uGUI按钮与离屏渲染，完整日志为 `UnityGame/Logs/ui-gameplay.log`。

| 范围 | 结果及画面 |
|---|---|
| 黄巾推荐首战 | 选关置首并显示推荐标记；黄巾胜利后“下一关”进入虎牢，全部关卡仍可自由进入 |
| 新手教学 | 未通关黄巾显示准备／前三波提示，第四波结束教学；真实按钮合法招募、保持守将选中时也能看到阶段提示；已通关和其它关不显示 |
| 武将信息 | 张飞、吕布、荀彧、吕蒙的战前／战中详情检查，真实冷却、蓄力和触发机制完整；基础威力不当作实际DPS |
| 备战调位 | 点守将→空位→移回；同一规则实例、同一棋兵及名签，军饷与招募历史保持；调位后升级正确作用于新阵位 |
| 失败复盘 | 自然空部署失败，显示实际突破敌军、路线1与剩余生命；取出事件不清空快照，保留统计及重开入口 |
| 预警优先 | 独立复制夹具用曹操及延迟招募马超，分别覆盖普通增伤和以Boss为目标的蓄力notice；真实Boss预警不被后续普通技能覆盖 |

PNG覆盖1920×1080、1280×720、2400×1080。每次截图前检查所有非空Text字形和裁切。主任务实际查看关卡、调位、失败、吕布与荀彧详情和第二波教学，未见上述页面文字裁切。

红证据保留：`ui-gameplay-red.log`（首战顺序）、`ui-gameplay-warning-red.log`（曹操普通提示）、`ui-gameplay-target-notice-red.log`（马超目标身份）；最终绿色为 `ui-gameplay.log`。预警夹具的敌军生命／速度调整仅在测试复制对象中，不写实际配置。

这些证据证明界面渲染与真实回调，不代替手机触控、安全区、长时间人工体验、系统事件投递和性能验收。完整五关人工平衡继续待验。
