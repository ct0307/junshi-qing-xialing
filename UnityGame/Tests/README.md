## 只读战斗情报接口

| 接口 | 语义 |
|---|---|
| `IsWaveActive` | 本波已启动且尚未清空，包括等待本波后续出兵；暂停保持，胜败后为false |
| `NextWaveCountdown` | 准备／波间返回当前进军倍率下距下一波的预计实秒；暂停冻结，活跃波与胜败后为0 |
| `RemainingEnemies` | 当前敌军加本波待出兵数量，不包含尚未启动的后续波次；波间为0 |
| `DefeatedCount` | 本局累计击退数，包含召唤单位，不因`DrainEvents`清空 |
| `LeakedCount` | 本局累计抵城数，包含造成直接失败的Boss，不因`DrainEvents`清空 |
| `GoldSpent` | 仅累计成功招募及升级的实际消费；无效、缺钱、暂停等失败操作不计入 |
| `DefeatReason` | 准备、运行和胜利均为空字符串；失败保留`Finish`产生的真实原因 |

这组接口不会改变出兵、战斗或经济规则。新增5项行为测试先在接口缺失时失败，再实现；覆盖准备/运行/暂停/终局、延迟出兵、波间、失败消费及跨事件消费的累计统计。
